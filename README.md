# Tab Volume Boost

Chromium 系ブラウザ向けの、タブごとに音量を調整できる拡張機能です。スライダーは 0～500%、数値入力では 500% を超える値も指定できます。日本語 UI、Manifest V3、外部ライブラリなし。

## インストール

1. この配布用フォルダーをダウンロードします。
2. Chrome や Edge の拡張機能ページ（`chrome://extensions` または `edge://extensions`）を開き、「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、この `manifest.json` があるフォルダーを選びます。

Chromium 116 以降が必要です。Chromium 系でもブラウザごとの実装差があるため、Chrome 以外での動作は使用するブラウザで確認してください。

## 使い方

1. 音量を変えたいタブを選び、ツールバーの拡張アイコンをクリックします。
2. スライダーか数値欄で倍率を決め、「このタブで開始」を押します。スライダーの上限は 500% です。それ以上は数値欄に入力してください。
3. 以後はポップアップを閉じても適用が続きます。再度開くと倍率を変更したり停止したりできます。

別のタブは別の倍率にできます。停止すると、そのタブはブラウザの通常の音声再生に戻ります。タブを閉じた場合も音声処理を解放します。

## 仕組みと制限

`chrome.tabCapture` でユーザーが選んだタブの音声を取得し、オフスクリーン文書内の Web Audio `GainNode` で増幅して再生します。キャプチャ中の元のタブ音声は Chromium により止められるため、二重再生にはなりません。タブごとに独立した GainNode を使い、ほかのタブや Windows 上の別のソフトウェアの音量設定は変更しません。

100% を超える設定は、通常のブラウザ音量の上限を超えるデジタル増幅です。数値欄に任意の上限は設けていませんが、ブラウザが扱えないほど大きい数値は適用できません。Windows のマスター音量、音声デバイスの物理的な最大出力、サイト側の制限は変更できません。大きな倍率では音割れが起きます。低い音量から試してください。

音声を取得できないページや、ブラウザ内部ページなど拡張機能が操作できないページでは開始できません。保護されたコンテンツは無音になる場合があります。ページの再読み込みやブラウザの休止などでキャプチャが終了した場合は、再度開始してください。

処理は開始したタブにだけ割り当てます。停止時にはそのタブのストリームとノードを解放し、最後のタブが停止すると AudioContext とオフスクリーン文書を閉じます。定期的な監視や常時動作するコンテンツスクリプトはありません。

## 権限とプライバシー

| 権限 | 用途 |
| --- | --- |
| `activeTab` | ユーザーが選んだタブを対象にする |
| `tabCapture` | そのタブの音声を取得する |
| `offscreen` | ポップアップを閉じた後も音声処理を続ける |

音声の録音、保存、送信はしません。ネットワーク通信もありません。
